Nowind

Fluid theme tokens and Prewind-style utility classes in plain CSS. Link one file; no build step.

Link it

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/kimgranlund/nowind@v0.8.0/dist/nowind.min.css">
