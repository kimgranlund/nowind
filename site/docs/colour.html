Colour

Two layers: palettes of twelve steps, and roles that name what a step is for. Use roles where the meaning matters (a page background, a hover fill, an error border) and steps where you want a specific value. Every value is a light-dark() pair, so both modes come from one class.

Palettes

9 palettes, each a radix-hct family of twelve steps (1–2 backgrounds, 3–5 component fills, 6–8 borders, 9–10 solids, 11–12 text) and twelve alpha steps for transparency.

accent-1 · blueMain brand accent: main actions, links, focus
Text on its solid: light in both modes (fg-accent-1-contrast)

Text on its solid: light in both modes (fg-accent-2-contrast)

Roles

A role is a step chosen for a use. Moving a role moves every part that uses it, and nothing that names a step.

Class names

A colour class is the property prefix plus the token name, minus the role group when it matches the prefix (fg-weak, bg-accent-1, border-weak; bg-component-accent-1 keeps its group). --border is border-default, because border is the width class; the reset draws every border in --border. Each property takes only its own roles: fg- with fg-*, on-solid-* and each palette's contrast (fg-accent-1-contrast, the primitive for text on a solid); bg- with bg-*, component-*, solid-*, surface, indicator and track; border- with border-*. Raw palette steps (fg-accent-1-9, bg-accent-1-9, border-accent-1-9) work with all three; alpha steps (neutral-a4) with bg- only. No outline colour classes: the reset sets the focus ring.

Text on a solid

Text on a step-9 fill takes that palette's contrast colour: fg-accent-1-contrast in primitives, fg-on-solid-accent-1 as a role. The accents and every status take light text in both modes; neutral is light, then dark.

Light and dark

Colours follow the reader's system setting. .light and .dark (or data-color-mode) force a scheme on any subtree. The toggle in this site's band sets data-color-mode on the root and remembers it; a script in the head applies it before the page paints. There is no dark: variant.
