Type and space

One fluid scale for each: sizes grow with the viewport between a phone and a wide screen, and every space step is a multiple of the base size, F. Sizes are the primitives; roles name a size, weight and face for a use.

Each text-* class sets the size and its line height, as Tailwind v4 does. Sizes are measured at the smallest and largest viewport.

Where each size goes

Which size each kind of text in an example takes. Sizes follow from what an element is, not from where it sits. the examples lint (scripts/templates.py) will classify each element by the 'identify' rule and check its size against this table; a rendered pass will check rows, hierarchy and icon pairing. The examples lint enforces it, and ?audit=type on any page checks the rendered rules below.

Side by side in one row, text shares a size, unless one side is a figure, a badge or a keycap, or the row aligns baselines (items-baseline), which is how a row mixes sizes on purpose. Within a surface: title >= body >= supporting; a dialog title is larger than its buttons. An icon takes the step of the text beside it: icon with text-base, icon-sm with text-sm, icon-lg on a title row.

Faces

  • --font-body: Body face: Inter, loaded from Google Fonts by theme.css (variable, 400–700, with optical sizes and italics).
  • --font-heading: Headings and display: Inter Tight, 500–800, loaded by theme.css.
  • --font-display: Display figures and numerals (prices, metrics): Inter Tight, the face that carries 800. Pair with font-extrabold and tracking-tight.
  • --font-mono: Kicker, code and figures: IBM Plex Mono 400 and 500, loaded by theme.css.
