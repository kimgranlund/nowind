Sortable table

Column headers hold buttons; aria-sort on the header says which column sorts the rows and in which order.

Example
Contoso48
Fabrikam12
Northwind7

Usage

Use
  • Show the sort direction with an icon and in aria-sort.
  • Sorting itself is a script's job; the classes only show the state.
Avoid
  • Sorting columns nobody compares.
