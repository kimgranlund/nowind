Convenience classes

The stacks that repeat most in the examples, as single classes in an optional second file. Each is written from its utility recipe and checked to render the same in every state, and any utility you add still wins. The rest of these docs show the utilities, so you can always see what a class is made of.

Link it

After the main stylesheet. The classes sit in a components layer that comes before the utilities.

Buttons

btn takes a tone; icon-btn holds one icon and an aria-label.

Small buttons and segments

btn-sm and segment sit only inside an inset container: a toolbar padded p-3xs, or a segmented group.

Fields and badges

field is the box; the input inside stays bare. Wrap a badge's text in a span.
