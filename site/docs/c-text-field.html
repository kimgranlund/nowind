Text field

A labelled field built from slots: a leading icon that says what kind of value it takes, a prefix, the input, a suffix and a trailing action. The box is the control; the input inside is bare.

Slots

Five slots, always in this order: leading icon, prefix, input, suffix, trailing. Any of them can be left out. An icon or a nested control at either end sits one margin from the edge, the same as in a button.

Data types

The leading icon names the kind of value; type, inputmode and autocomplete give the right keyboard and autofill. Units sit in the suffix, never in the value.

States

The box shows every state of the input inside it: focus-within: turns the border accent, has-invalid: turns it danger. A disabled or read-only field says so with its fill as well as its text.

Use lowercase letters, numbers and underscores.

Sizes

Every length here comes from the base size, so a smaller or larger component is a region with a smaller or larger base: scope text-sm or scope text-lg around it. Height, padding, gaps, icons and corners all recompute and still nest; inside the scope the component's text inherits the scope's size. The default needs no wrapper.

Usage

Use
  • A leading icon for the kind of value, so a long form scans by shape.
  • Prefixes and suffixes for parts the person doesn't type: a scheme, a currency sign, a unit.
  • gap-2xs between label, box and help; gap-md between fields.
Avoid
  • A placeholder instead of a label.
  • A unit inside the value ("72.5 kg"): it breaks number keyboards and parsing.
  • More than one trailing action in a box.
