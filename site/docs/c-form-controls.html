Checkbox, radio and switch

Native inputs drawn by the reset at Affine's mark size. A switch is a checkbox with role="switch".

Example

Usage

Use
  • A switch for a setting that applies at once; a checkbox for one that waits for Save.
  • mark-sm or mark-lg to change the size.
Avoid
  • Wrapping inputs in custom elements; the reset styles the native ones.
