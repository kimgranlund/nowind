Page grid and shell

The classes that place a page: the column gutter and edge padding, the shell's sidebar, header and reading measure, the container levels and the tiers. Each length is derived from the base size --F.

Nowind 0.9.0 · from classes.md

Grid columns are grid-cols-1 to grid-cols-12 with col-span-*. These classes set the space between and around them.

Radius and nesting

After Affine UI, one unit runs the whole scale: each radius step is one margin (M) from the next (xs = control − M, sm = control, md = control + M, lg = control + 2M, xl = control + 3M), and the padding between levels is the inset (I = M − border). So a bordered container padded p-inset holds items one radius step down, concentrically: (r + M) − (M − B) − B = r. Pairs: rounded-md p-inset holds rounded-sm; rounded-lg p-inset holds rounded-md; rounded-sm p-inset holds rounded-xs. Any other padding uses rounded-inner (the parent's radius minus its padding and border).

ClassValueUse
rounded-xsradius-nested (control − margin)A part inside a control or an item inside a popup; class rounded-xs.
rounded-smradius-controlA control; class rounded-sm.
rounded-mdradius-surface (control + margin)A card, popover or toast; class rounded-md.
rounded-lgradius-dialog (control + 2 × margin)A dialog; class rounded-lg.
rounded-xlcontrol + 3 × marginA sheet or hero panel; class rounded-xl.
