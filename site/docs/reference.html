Page grid and shell

The classes that place a page: the column gutter and edge padding, the shell's sidebar, header and reading measure, the container levels and the tiers. Each length is derived from the base size --F.

Nowind 0.8.0 · from classes.md

Page grid

Grid columns are grid-cols-1 to grid-cols-12 with col-span-*. These classes set the space between and around them.

ClassDeclarationDerived from
gap-gridgap: var(--grid-gutter)2 × margin
gap-x-gridcolumn-gap: var(--grid-gutter)2 × margin
p-grid-insetpadding: var(--grid-inset)Half a gutter
px-gridpadding-inline: var(--grid-margin-regular)One slot
px-grid-compactpadding-inline: var(--grid-margin-compact)The larger of a gutter and half a slot

Shell lengths

The app shell's lengths grow with the type, so a sidebar that fits its labels on a phone still fits them on a wide screen.

ClassDeclarationDerived from
w-sidebarwidth: var(--shell-sidebar-width)16F + 16px
w-railwidth: var(--shell-rail-width)Control height + 2 slots
h-headerheight: var(--shell-header-height)Control height + 1 slot
min-h-headermin-height: var(--shell-header-height)Control height + 1 slot
max-w-measuremax-width: var(--shell-measure)44F
Note

Breakpoint variants cover layout only: display, grid, flex, alignment, widths and gaps. There is no lg:w-sidebar; show and hide the sidebar with hidden lg:flex instead.

Container levels

Pad a box by what it is, not by a size. The values are at a 16px base.

ClassUseAt 16px
p-surfaceCard or panel23px
p-dialogDialog37px
p-regionSidebar24px
p-pagePage content area38px
gap-fieldLabel to control, control to help7px
gap-rowControls side by side14px
gap-groupField to field19px
gap-sectionBefore a new section24px
