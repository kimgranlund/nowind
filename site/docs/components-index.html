Components

26 components, each a single snippet of HTML built only from Nowind utility classes. Every page shows the component live, its code to copy, when to use it and the classes it uses.

Actions

Button Starts an action. One control height tall, padded by the text edge, with an icon side that steps in by one margin. Icon button A button with only an icon. size-control makes it square and the same height as a text button; size-nested is the small size for inside a toolbar or field. Segmented control A set of mutually exclusive options. The pressed segment is styled by aria-pressed, not by a class.

Status

Badge A short label for a status or category, at the nested control size. Alert A message about the page or a task, tinted by its status. One line sits in the geometry of a field; a titled alert puts a large icon beside its title and the detail below. Toast A brief confirmation on the inverse colours. One line keeps its action inline; a toast with detail stacks title, detail and actions in one text column, with the icon and dismiss on the first line.

Forms

Text field A labelled field built from slots: a leading icon that says what kind of value it takes, a prefix, the input, a suffix and a trailing action. The box is the control; the input inside is bare. Select A native select. select-base turns on the customizable select, so the picker takes the theme; a <button> holding <selectedcontent> lets a long value end in an ellipsis instead of wrapping. Checkbox, radio and switch Native inputs drawn by the reset at Affine's mark size. A switch is a checkbox with role="switch". Combobox A text field with suggestions, using the native list attribute and a <datalist>. Date range Two native date fields grouped as one, with their own labels.

Layout

Card A surface that groups related content, padded at the surface level. Media card A card led by a 16:9 media area, then a title, a line of detail and its author.

Navigation

Tabs Switches between views of the same thing. The selected tab is styled by aria-selected. Breadcrumbs Shows where a page sits in the hierarchy. Pagination Moves through pages of results. The current page is styled by aria-current.

Overlays

Popover menu A menu that opens with popovertarget and sits against its button with anchor-bottom. No script. Dialog A modal <dialog> opened with the command attribute; the reset dims the page behind it. Tooltip A hint that shows when its trigger is hovered or focused. The wrapper is a group; the hint uses group-hover: and group-focus-within:. No script.

Disclosure

Accordion Sections that open and close, built from <details>.

Data display

Avatar and group Initials on an accent solid, one control height square; a group overlaps them. Progress bar Native progress and meter, themed by the reset, or a track and a fill sized with a fraction class. Table Rows of records in a surface that scrolls sideways on narrow screens. Sortable table Column headers hold buttons; aria-sort on the header says which column sorts the rows and in which order.

Feedback

Empty state What a view shows before it has content, with the action that fills it. Spinner and skeleton animate-spin for a short wait, animate-pulse placeholders for content that's on its way.
