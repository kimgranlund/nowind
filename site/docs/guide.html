Guide

Lay out a docs page

Build a documentation page from Nowind's shell lengths, its 12-column grid and four type roles. Every part on this page is the template you can copy.

Applies to Nowind 0.14.0

The frame

Every page on the site has the same three parts, after Vignelli's Unigrid: an inverse band with the four sections, a bar under a heavy rule with where you are, search and the next page, and the page itself, a stack of blocks. The band and the bar stick to the top together; the page scrolls under them.

The band is h-header tall and follows the base size, so it grows with the type from a phone to a wide screen. scroll-pt-4xl on html keeps a linked block clear of the band and the bar.

Note

Keep one scroller: the page. Don't make main a scroll box; browsers paint very tall nested scrollers badly, and in-page links, find and the back button work against the window.

The block

Every block hangs from a label column: its label in the first three of twelve columns, its content in the other nine. A component's example, a palette and a release in the changelog all have this one shape. Below 768px the label sits above the content.

WidthSectionsLabel
Under 768pxIn the site mapAbove the content
768px (md:) and upIn the bandColumns 1–3, content 4–12

The reading column

Prose stops at max-w-text, 68 characters of its own font. The article is a tier-content region, so its section gaps and page padding are one and a half times the product rhythm and its measure grows with the tier's larger base size.

Tip

Put the tier on main only. The band and the section row stay in the product tier, so they look the same on every page.

Four type sizes

A docs page needs four sizes and no more. Contrast between them is the hierarchy, so they sit far apart: a display size for the page title, a heading size for sections, the base size for reading and controls, and a small size for labels and code.

SizeClassesUsed for
Displaytext-display-smThe page title, once per page
Headingtext-heading-mdSection headings, each under a rule
Basetext-body-md, text-subtitle, text-title-smProse, subheadings, navigation and buttons
Smalltext-caption, text-label, text-kicker, text-mono-smMetadata, table heads, kickers and code

Weight, not size, separates a subheading from prose: text-subtitle is the base size at a semibold weight.

Callouts, code and tables

A callout is a coloured rule on the left, a word and a sentence. The colour codes the kind and the word says it, so the meaning never depends on colour alone.

Warning

A callout interrupts the reader. Use at most one per section.

A code block is a figure: the file name and language in a caption, the code in a pre that scrolls sideways rather than wrapping. Tables wrap their cells instead of scrolling, so the code block is the only thing on the page that scrolls sideways.

Search

Press ⌘K or Ctrl+K, or /, on any page to search every page, block heading, component and class. The index, search.json, is written with the pages, so it never falls behind.

Note

The search script is the only script every page loads. Without it the band, the section row and every link still work.
