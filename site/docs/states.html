States and variants

A variant applies a class only in a state: hover:bg-neutral-4, selected:border-accent-1-8, md:flex. Each variant covers a fixed set of classes, mostly colours, so the stylesheet stays one file. The markup drives the look: set the ARIA attribute and the class follows.

Selected, pressed and current

Tabs read aria-selected, segments aria-pressed, the current page aria-current. Hover any of them: a chosen item never looks hovered.

Checked, invalid and disabled

These follow the browser's own state: tick a box, flip the switch, or leave a field invalid and move on (:user-invalid).

Use lowercase letters, numbers and underscores.

Group variants

Put group on a parent; a child reacts to its state. These cover opacity, visibility, rotation and the text roles. Hover or focus the link for its tooltip; open the menu and its caret turns.

Breakpoints

sm:, md:, lg:, xl:, 2xl: (read from the --breakpoint-* tokens) apply to layout: display, grid columns and spans, flex direction, wrap, basis, justify, align, text alignment, widths, inline and all-side padding and gaps. Margins, colours, type, position, heights and overflow have no breakpoint variants.

Resize the window: one column, two from 640px, four from 1536px.

Container queries

@sm:, @md:, @lg: (384, 448 and 512px, read from the --container-* tokens) apply a component's layout classes (display, flex direction and wrap, grid columns and spans, basis, gaps, alignment, text alignment) when the nearest ancestor with @container (container-type: inline-size) is at least that wide, so a component lays itself out by its own width rather than the viewport's.

The same card twice: in the narrow column it stacks, in the wide one it turns into a row, at one window width.

State layer

state: a state layer. An ::after wash of currentColor under the content, at --state-hover (0.12), --state-focus (0.14), --state-selected (0.16, also pressed, expanded, current and a checked child) and --state-active (0.2); none when disabled. One class covers every state in any palette, in place of a hover: and active: class per step; the element keeps its own radius.

Hover and press each: one layer tints every fill, in its own text colour.

Transitions and focus

Every interactive element (links, buttons, summaries, fields, labels, and the button, tab, option, menuitem and switch roles) transitions its colours, opacity, shadow and transforms by default, at the motion duration and easing. Reduced motion cuts it. Anything else that changes with state names transition.

Focus: buttons, links and checkable controls get a 2px accent ring on :focus-visible. A text field draws the ring over its own border, so a border class can't hide it, and a field box (cursor-text) draws it on the box while its bare input draws none.

Hover to see the fade, then press Tab to walk the ring along the toolbar.

Indicators

An indicator follows the state it shows. A caret turns over when its disclosure or menu opens: put group on the details or on the wrapper holding the button and its popover.

Open each row: its caret turns with it.
