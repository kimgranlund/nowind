States and variants

A variant applies a class only in a state: hover:bg-neutral-4, selected:border-accent-1-8, md:flex. Each variant covers a fixed set of classes, mostly colours, so the stylesheet stays one file. The markup drives the look: set the ARIA attribute and the class follows.

Group variants

Put group on a parent; a child reacts to its state. These cover opacity, visibility, rotation and the text roles.

VariantWhenClasses
group-hover:the .group is hovered58

Breakpoints

sm:, md:, lg:, xl:, 2xl: (read from the --breakpoint-* tokens) apply to layout: display, grid columns and spans, flex direction, wrap, basis, justify, align, text alignment, widths, heights, position, top, overflow, padding and gaps. Margins, colours and type have no breakpoint variants.

Container queries

@sm:, @md:, @lg:, @xl:, @2xl: (384, 448, 512, 576 and 672px, read from the --container-* tokens) apply the same layout classes when the nearest ancestor with @container (container-type: inline-size) is at least that wide, so a component lays itself out by its own width rather than the viewport's.

Transitions and focus

Every interactive element (links, buttons, summaries, fields, labels, and the button, tab, option, menuitem and switch roles) transitions its colours, opacity, shadow and transforms by default, at the motion duration and easing. Reduced motion cuts it. Anything else that changes with state names transition.

Focus: buttons, links and checkable controls get a 2px accent ring on :focus-visible. Text fields get no ring; their border turns accent, and a field box shows its input's focus with focus-within:.

Indicators

An indicator follows the state it shows. A caret turns over when its disclosure or menu opens: put group on the details or on the wrapper holding the button and its popover.
