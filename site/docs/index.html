Templates

A documentation system for Nowind

Four page templates for a docs site, built only from Nowind's utility classes. One frame, one grid, four type sizes, one accent. Copy a page and replace the words.

No style element, no style attribute, no script

Purpose

A documentation reader is looking for one thing and wants to find it fast. These templates keep every part in the same place on every page, so after one visit the reader stops looking at the frame and reads the content.

An inverse band with the four sections, then a bar under a heavy rule with the site map, search and the next page, then the page as a stack of blocks. Only the band sticks; the page scrolls as a whole. Below 768px the sections are reached through the site map.

Twelve columns, spaced by gap-grid and held off the edge by px-grid. Every block puts its label in three columns and its content in nine; below 768px the two stack. Prose inside a block stops at max-w-measure.

Type scale

Four sizes, far apart. Weight separates roles that share a size.

SampleSize and useClasses

Page title, --text-4xl		text-display-sm
AaHeading

AaBase
Prose, subheads, nav, buttons, --text-base		text-body-md · text-subtitle · text-title-sm

Metadata, labels, code, --text-sm		text-caption · text-label · text-kicker · text-mono-sm

One family carries everything: Inter for text, Inter Tight for display and headings, IBM Plex Mono for code and kickers. Nowind has no serif, so these pages have none.

Colour and form

  • Neutral roles for everything: bg, bg-strong, fg, fg-weak, border-weak.
  • One accent, accent-1, for links, the current page, the primary button, entry icons and the Latest release badge.
  • Status colours only in callouts, each paired with its word: Note, Tip, Warning.
  • Square corners and no shadows. Rules and white space do the separating.
  • Every colour is a role class, so the pages follow light and dark mode by themselves.

The templates

  • Docs homeA landing page: title, two actions, four entry points on the grid, an install snippet and the figures.
  • GuideThe band, the bar with the site map and search, and the block with its label column.
  • ReferenceTables of classes and declarations, with code.
  • ChangelogReleases as rows on a 1 + 3 grid, with a release index in place of the contents.

Known limits

  • Margins and type have no breakpoint variants; padding, position, overflow, widths and gaps do. The templates rely on the fluid type scale.
  • Search needs a web server: browsers block loading the index from a file.
