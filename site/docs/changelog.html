Changelog

Release notes

What changed in each release of Nowind, newest first. Pin a release in the CDN link and your site changes only when you change the version.

Pin a release

0.8.0

2026-11-25 Latest
  • Group variants

    group on a parent, group-hover:, group-focus-within: and group-open: on a child (opacity, visibility and fg-*), for tooltips and reveal-on-hover.

  • Offsets

    top-full, bottom-full, left-full, right-full.

  • Component docs

    Tooltip, combobox, sortable table, date range and media card (26 pages).

  • Forced colors

    In Windows High Contrast, controls and overlays keep an outline, selected and current items get a Highlight outline, and checkboxes, radios, switches and sliders are redrawn in system colors.

0.7.0

2026-11-25
  • Renamed

    Text-color role classes drop text-: text-fg-weak is now fg-weak, text-fg-accent-1 is fg-accent-1, with their variants (hover:fg, aria-selected:fg). text-on-solid-* and the raw-step text-* classes are unchanged.

0.6.0

2026-11-25
  • Component docs

    A page per component in templates/ (21 so far), each with the component live, its HTML to copy, when to use it and when not to, and the classes it uses; plus an index. Content lives in scripts/component_docs.py.

0.5.0

2026-11-25
  • Tiers grow the type

    Inside tier-content and tier-brand the whole type scale and the type roles grow with the tier's body size.

  • Sticky under a header

    top-header, h-below-header, max-h-below-header.

  • Breakpoints

    Now cover padding, position, top-*, overflow and heights (lg:sticky, md:p-surface, lg:overflow-y-auto).

  • Level padding sides

    pt- and pb- for surface, dialog, region and page.

  • Reset

    Inline code no longer wraps at hyphens; list-none also hides Safari's <summary> marker.

0.4.0

2026-11-25
  • Popovers, select, animation

    anchor-* (CSS anchor positioning for popovers), select-base (customizable select), animate-spin, animate-pulse.

  • Showcase components

    Accordion, dropdown, modal dialog, avatar group, progress, stepper, input groups, description list, activity, pricing, dropzone, tags, rating, popover menu and info, toast stack, loading states, toolbar, notifications, command palette.

  • Fixed

    The reset's backdrop and selection rules were ignored (pseudo-elements in :where()); the scrim now dims only modal dialogs.

  • State variants

    active:, focus-visible:, aria-selected:, aria-current:, aria-pressed:, aria-expanded:, open:, aria-invalid:, disabled:, colors only, for the neutral and accent roles. The showcase's tabs, toggles, nav and pagination now take their look from ARIA state.

  • Docs-site templates

    templates/ holds a docs home, a guide with sidebar and table of contents, a reference page and a changelog, built only from utility classes and generated by scripts/templates.py.

0.3.0

2026-11-25
  • Fonts

    theme.css and the bundle load Inter, Inter Tight and IBM Plex Mono from Google Fonts. --font-heading is Inter Tight and --font-mono IBM Plex Mono.

  • Motion

    Massimo's springs (--ease-smooth, --ease-snappy, --ease-bouncy) as CSS linear() easings with their durations, ease curves, and transition-*, duration-*, ease-* classes.

  • Page grid and shell

    Affine's grid gutter, inset and edge margins, and shell lengths (sidebar, rail, header, measure, dock width) with gap-grid, p-grid-inset, px-grid, w-sidebar, w-rail, h-header, max-w-measure.

  • Form marks

    The reset draws checkboxes, radios, switches (role="switch") and sliders at Affine's mark sizes; mark-sm, mark-lg.

  • Materials

    Massimo's flat, physical, frosted, glass and outline materials (material-* on a region, relief-* on a part), with generated paint tokens.

  • Dev server

    scripts/serve.mjs serves previews with caching off.

0.2.0

2026-11-25
  • Inverse colors

    --bg-inverse, --fg-inverse, --fg-inverse-weak and their classes, for toasts and tooltips.

  • Hover borders

    hover:border-* for the border roles (hover:border-border-strong).

  • Grid

    grid-cols-1 … grid-cols-12, grid-cols-none, col-span-1 … col-span-12, col-span-full.

  • Fractions

    w-1/2, w-1/3, w-2/3, w-1/4, w-3/4, fifths, and matching basis-*.

  • Breakpoints

    Now also cover grid columns and spans, basis, widths and gaps.

0.1.0

2026-11-25

First release.

Theme

  • Colors

    Nine palettes on the radix-hct-colors scales: accent-1 (blue), accent-2 (violet), accent-3 (plum), accent-4 (crimson), neutral (slate), danger (red), warning (amber), success (green), info (indigo). Each has steps 1–12, alpha steps a1–a12 and a contrast color, all in light-dark().

  • Color roles

    bg, component, border, solid, on-solid and fg for every palette, with -weak and -strong steps; Radix companions surface, indicator, track; --scrim for backdrops.

  • Type

    A fluid Utopia scale --text-xs … --text-6xl with Tailwind v4 line-height companions; 29 semantic roles after Massimo (--heading-md, --body-md, --figure, …); a kicker at three sizes.

  • Geometry

    Every length from one base size --F, after Affine UI: slot, margin, inset, control height, radii, icon sizes, container levels and tiers. At the root --F follows the fluid body size; a .scope or tier sets its own.

  • Space

    --space-3xs … --space-4xl as multiples of --F.

  • Shadows

    Compound casts and recesses after Massimo, --shadow-xs … --shadow-xl and --inset-shadow-xs, --inset-shadow-sm.

Utilities

  • About 1,200 Prewind-style classes with Tailwind v4 names where they overlap; hover: for role colors, opacity and cursor; sm: … 2xl: for layout.

  • Affine container levels (p-surface, p-dialog, gap-field, gap-group, …), tiers (tier-content, tier-brand), control and icon utilities for Phosphor icons.

  • A 2026 reset in @layer reset, every selector in :where().

Tooling

  • dist/nowind.min.css: the whole system in one file.

  • Generators for the type and space scales, shadows, utilities and bundle; scripts/check.mjs with a self-test.

  • specimen.html, components.html, utilities.html and classes.md.
