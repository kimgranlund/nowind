Resets

Nowind starts from a reset that clears the browser's styles, then a layer of element defaults that gives bare buttons, fields and tables a finished look. Both sit in early layers, under :where(), so your CSS and any class win.

The reset

Every element gets box-sizing: border-box and zero-width solid borders, so a border class sets only the width. Headings take the heading roles unless a text-* class sizes them. Links keep their underline, and text wraps with balanced headings and pretty paragraphs. Checkboxes, radios, switches, sliders, progress and meter are drawn from the theme. Buttons start transparent and unpadded; the element defaults below then style them. Focus draws a ring, interactive elements transition, and reduced motion turns that off.

Element defaults

The defaults layer gives bare elements a finished look: buttons, text fields, selects, textareas, checkboxes, radios, switches, sliders, links, labels and table cells. Structure does the rest, with no class anywhere: a form stacks its parts; a div of buttons becomes a row; small after a field is its help text; role="status", "alert" and "note" become info, danger and neutral notes; a role="group" of aria-pressed buttons becomes a segmented control; and a classless main centres the page. data-tone (danger, accent, success, warning, info) tints a button or a note. A button with type="submit" takes the primary fill. Nothing below carries a class.

The defaults fill only what an element's classes leave unset, so a utility class still wins, and a utility-built control picks up a default for any property it doesn't set.

Override a default

Four ways, from widest to narrowest. A token on :root changes every element; on a region, only that region; a rule in @layer styles beats the defaults outright; a utility class changes one element.

Layers

Nowind declares @layer reset, defaults, styles, components, nowind. The reset sits in reset and the element defaults in defaults; put your own CSS in styles, where it beats both; the optional convenience classes fill components; the utilities in nowind win over all of them.
