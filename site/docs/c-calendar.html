Calendar

A month as a seven-column grid of day buttons. The chosen day is aria-pressed, today carries aria-current="date", and days from the next month are quieter.

Example

March 2027
MoTuWeThFrSaSu

Usage

Use
  • Label each day with the full date, so a screen reader doesn't read a bare number.
  • Prefer the native date field (see Date range) unless people need to see the month.
Avoid
  • A calendar for a date years away, such as a birthday; let people type it.
