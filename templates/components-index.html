Components

Components

26 components, each a single snippet of HTML built only from Nowind utility classes. Every page shows the component live, its code to copy, when to use it and the classes it uses.

Actions

Button Starts an action. One control height tall, padded by the text edge, with an icon side that steps in by one margin. Icon button A button with only an icon. The same padding rules make it exactly one control height square. Segmented control A set of mutually exclusive options. The pressed segment is styled by aria-pressed, not by a class.

Status

Badge A short label for a status or category, at the nested control size. Alert A message about the page or a task, tinted by its status. Toast A brief confirmation on the inverse colors, with an optional action.

Forms

Text field A labelled input with help text. aria-invalid switches the border to danger. Select A native select. select-base turns on the customizable select, so the picker takes the theme. Checkbox, radio and switch Native inputs drawn by the reset at Affine's mark size. A switch is a checkbox with role="switch". Combobox A text field with suggestions, using the native list attribute and a <datalist>. Date range Two native date fields grouped as one, with their own labels.

Layout

Card A surface that groups related content, padded at the surface level. Media card A card led by a 16:9 media area, then a title, a line of detail and its author.

Navigation

Tabs Switches between views of the same thing. The selected tab is styled by aria-selected. Breadcrumbs Shows where a page sits in the hierarchy. Pagination Moves through pages of results. The current page is styled by aria-current.

Overlays

Popover menu A menu that opens with popovertarget and sits against its button with anchor-bottom. No script. Dialog A modal <dialog> opened with the command attribute; the reset dims the page behind it. Tooltip A hint that shows when its trigger is hovered or focused. The wrapper is a group; the hint uses group-hover: and group-focus-within:. No script.

Disclosure

Accordion Sections that open and close, built from <details>.

Data display

Avatar and group Initials on an accent solid, one control height square; a group overlaps them. Progress bar A track and a fill sized with a fraction class. Table Rows of records in a surface that scrolls sideways on narrow screens. Sortable table Column headers hold buttons; aria-sort on the header says which column sorts the rows and in which order.

Feedback

Empty state What a view shows before it has content, with the action that fills it. Spinner and skeleton animate-spin for a short wait, animate-pulse placeholders for content that's on its way.
