# Changelog

## Unreleased

- **The command palette keeps one height,** 600px (new `--shell-command-height` and `h-command`, which stops at the viewport below the header), whatever the results, and its list scrolls inside it.
- **A sortable end-aligned column puts its sort icon before the label,** so the label lines up with the numbers below instead of the icon box's bearing leaving a ragged edge. The empty state's icon sits in a larger circle (`p-sm` around `icon-lg`).
- **Table cells keep the control height:** a cell ignores `min-height`, so `h-control` and `h-nested` on a `td` or `th` set `height`, which a cell already treats as a minimum.
- **Site fixes:** the site's cards, code figures, tables and lists take `rounded-md`; the home page's link cards align their icon and arrow with the title; a sortable table's header row is as tall as a plain one (its cells drop the default block padding, `py-0`); and the empty state's icon is `icon-lg` in a `size-control` marker.
- **Titles are the next size up from the body:** a title in a card, list, alert, toast or dialog is `text-lg font-semibold` (was `text-base`), in the size contract, the examples and the docs. A one-line message stays at the body size.
- **Badges drop their icon gap:** the nested icon box already leaves the glyph about 3px on each side, so the extra `gap-gutter-half` set the label twice as far from the icon as the icon sits from the edge. The `badge` convenience class and the geometry contract follow.
- **Colour page swatches are square**, and step 9, each palette's solid, is a circle.
- **The bar's search field fills the width** between the site-map button and the page arrows.

## 0.18.0 (2026-11-27)

- **A smaller semantic set (breaking).** Semantic classes now name only decisions a raw step can't: 149, down from 267. Every token stays; only these classes go. Use the raw step or the kept role instead:
  - `accent-2` to `accent-4` role classes (`bg-accent-2`, `bg-component-accent-3`, `bg-solid-accent-4`, `fg-accent-2-weak`, `border-accent-3`, `fg-on-solid-accent-4`, …) → the raw steps they alias: `bg-accent-N-1`, `bg-accent-N-4`, `bg-accent-N-9`, `fg-accent-N-11`, `border-accent-N-7`, `fg-accent-N-contrast` (weak and strong rungs one step down or up).
  - `bg-*-surface` → `bg-{palette}-a2`; `bg-*-indicator` and `bg-*-track` → `bg-{palette}-9`.
  - The rarely used rungs of accent-1 and the statuses: `bg-{p}-strong` → `bg-{p}-2`; `bg-component-{p}-strong` → `bg-{p}-5`; `fg-{p}-subtle` → `fg-{p}-8`; `fg-{p}-strong` → `fg-{p}-12`; `border-{p}-weak` → `border-{p}-6`; `border-{p}-strong` → `border-{p}-8`.
  - `text-display-lg`, `text-display-md` → `text-display`; `text-body-lg` → `text-lead`; `text-footnote` → `text-caption`; `text-quote` → `text-lead` with `italic`; `text-mono` → `text-mono-sm` or `font-mono`; `text-kicker-lg` → `text-kicker`.
  - `pt-`/`pb-` for surface, dialog and region → `py-*` or the space scale; `mt-section`, `mb-section` → `gap-section` on the parent; `min-h-header` → `h-header` (a minimum now).
- **Fixes from the docs:** the selected tab no longer shows a border on its top and sides; a select in a field's slot keeps its own width instead of sharing the row; a sortable table's header matches a plain table's; and a meter's value fills its track in Chromium, with no ring. A new examples-lint check fails a button or field whose utilities set part of a property the defaults layer fills: a border on some sides, a field in a row with no width, a button in a table cell.
- **No fixed heights:** `h-control`, `h-nested`, `h-header`, `size-control` and `size-nested` now set a minimum height (and the squares a minimum width), as do the element defaults for buttons, fields and segmented groups, so a label that wraps or a larger text size grows its control instead of overflowing it. Inside a control, `h-full` stretches the item to the control's height. The site map's links wrap inside their highlight.
- **Truncated labels keep their descenders:** a `truncate` label in a control is trimmed to cap height like any label, and its clip now reaches below the baseline, so a “p” or “g” isn't cut off.

## 0.1.0 (2026-11-25)

First release.

### Theme

- **Colors:** nine palettes on the radix-hct-colors scales: `accent-1` (blue), `accent-2` (violet), `accent-3` (plum), `accent-4` (crimson), `neutral` (slate), `danger` (red), `warning` (amber), `success` (green), `info` (indigo). Each has steps 1–12, alpha steps a1–a12 and a contrast color, all in `light-dark()`.
- **Color roles:** `bg`, `component`, `border`, `solid`, `on-solid` and `fg` for every palette, with `-weak` and `-strong` steps; Radix companions `surface`, `indicator`, `track`; `--scrim` for backdrops.
- **Type:** a fluid Utopia scale `--text-xs` … `--text-6xl` with Tailwind v4 line-height companions; 29 semantic roles after Massimo (`--heading-md`, `--body-md`, `--figure`, …); a kicker at three sizes.
- **Geometry:** every length from one base size `--F`, after Affine UI: slot, margin, inset, control height, radii, icon sizes, container levels and tiers. At the root `--F` follows the fluid body size; a `.scope` or tier sets its own.
- **Space:** `--space-3xs` … `--space-4xl` as multiples of `--F`.
- **Shadows:** compound casts and recesses after Massimo, `--shadow-xs` … `--shadow-xl` and `--inset-shadow-xs`, `--inset-shadow-sm`.

### Utilities

- About 1,200 Prewind-style classes with Tailwind v4 names where they overlap; `hover:` for role colors, opacity and cursor; `sm:` … `2xl:` for layout.
- Affine container levels (`p-surface`, `p-dialog`, `gap-field`, `gap-group`, …), tiers (`tier-content`, `tier-brand`), control and icon utilities for Phosphor icons.
- A 2026 reset in `@layer reset`, every selector in `:where()`.

### Tooling

- `dist/nowind.min.css`: the whole system in one file.
- Generators for the type and space scales, shadows, utilities and bundle; `scripts/check.mjs` with a self-test.
- `specimen.html`, `components.html`, `utilities.html` and `classes.md`.
